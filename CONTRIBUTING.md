# Contributing

Thanks for contributing to `awesome-berlin-data`.

This repository is a curated list of open data sources, APIs, tools, applications, and related resources for Berlin. The goal is to keep entries useful, concise, and easy to scan.

## What To Add

Add resources that are relevant to Berlin and fit one of the existing sections in `README.md`, for example:

- open datasets
- APIs or API documentation
- data tools or starter kits
- interactive maps or visualizations
- data journalism or research projects

## Entry Guidelines

Each entry should:

- link directly to the project, dataset, or primary source
- have a short description explaining what it is and why it is useful
- stay concise and factual
- mention important context such as unofficial status or outdated data when relevant

## Before Opening A Pull Request

Please check that:

- the resource is clearly related to Berlin
- it is added to the most appropriate section
- it is not already listed elsewhere in the file
- the description matches the style of nearby entries
- the link works

## Updating Existing Entries

Improvements are welcome, especially:

- fixing broken links
- clarifying descriptions
- marking outdated resources
- removing duplicates
- adding better primary-source links

## Pull Requests

Small, focused pull requests are preferred. If a change is debatable, open an issue first so the discussion stays clear.
